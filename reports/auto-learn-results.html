What this run actually measured

The standalone local run called the current production acceptance policy for each pair. The cloud run used the existing entity-focused prompt, temperature 0.3, and all 392 IDs with exact source/target values in one request. No example sentences or expected labels were sent to the model.

“Suggested” means the pair passed the reviewer decision. This does not test recording, extraction, observation thresholds, the per-observation suggestion limit, storage, approval, or the UI. Why the four local misses happened

The inflection heuristic interprets Postgress and RedisS as plural-like forms; Huging and Hugging share an inferred root; zeded looks like a past-tense form of zed. The filter therefore suppresses these useful pairs.
